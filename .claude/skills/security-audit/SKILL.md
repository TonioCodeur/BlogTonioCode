# Skill Title

Conducting a Security Audit for the Project

## Instructions

Conduct a comprehensive security audit for the project using best practices and available tools. Identify potential vulnerabilities, security flaws, and propose recommendations to strengthen the project's security. Ensure to cover all relevant aspects, including dependencies, configurations, and secure development practices.

It is necessary to:
- check the project's dependencies to detect known vulnerabilities
- analyze security configurations to identify potential flaws
- evaluate development practices to ensure they follow recommended security standards
- provide a detailed report with identified vulnerabilities and recommendations to fix them
- verify that no sensitive data is exposed in the code or configurations
- ensure that authentication and authorization mechanisms are correctly implemented and secure
- test the project's entry points to detect vulnerabilities such as injections, XSS attacks, etc.
- recommend tools and practices to maintain the project's security in the long term
